# 🍕 App Pizzaria — Android Nativo

Aplicativo móvel desenvolvido em **Java** para a atividade prática da disciplina de Desenvolvimento para Dispositivos Móveis.

## 📱 Funcionalidades
- **Login e Autenticação:** Entrada com nome do usuário e persistência local via `SharedPreferences`.
- **Cardápio Interativo:** Listagem dinâmica com `RecyclerView` e `CardView` exibindo ingredientes, preço e imagem.
- **Navegação e Detalhes:** Envio de dados via `Intent` e objeto serializado (`Serializable`) para visualização completa do item.
- **Encerramento de Sessão:** Botão de logout que limpa os dados salvos em disco.

## 🛠️ Tecnologias Utilizadas
- Java 8+
- Android SDK (API 24+)
- Material Design Components
- SharedPreferences
- RecyclerView
